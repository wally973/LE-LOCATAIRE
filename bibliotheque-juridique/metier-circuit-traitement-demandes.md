# Fiche opérationnelle — Circuit de traitement des demandes
Source professionnelle : pratiques de traitement des réclamations logement social
Date de publication : fiche interne — 2026-06-26
Version : opérationnelle

## Résumé
Le circuit de traitement d'une demande doit rester simple et traçable.
La demande arrive par locataire, gardien, téléphone, accueil, application ou autre canal.
Elle doit être enregistrée avec lieu, photo si possible, description courte, urgence, auteur du signalement et périmètre.
La première classification sépare privatif / commun / nuisance / sinistre / sécurité / administratif.
La deuxième classification oriente vers menu travail, travail technique, gestion de proximité, assurance, contentieux ou recours.
Le gardien peut constater et traiter les demandes simples.
Le responsable de cité pilote les parties communes, les nuisances, les marchés et les prestataires de proximité.
Le technicien prend les demandes techniques, les diagnostics, la sécurité et les travaux complexes.
Le bailleur/admin suit les décisions, coûts, contentieux, responsabilités et clôtures.
Pour Grock, cette fiche sert à transformer une phrase locataire en action orientée, sans perdre Marie dans une procédure.

## Étapes du circuit
1. Réception : message, photo, lieu, bâtiment, logement, partie commune, urgence.
2. Compréhension : reformuler en une phrase simple.
3. Classification : privatif / commun / nuisance / technique / menu travail / sécurité.
4. Orientation : gardien, responsable de cité, technicien, bailleur, assurance ou recours.
5. Action : constat, demande d'intervention, ordre prestataire, consigne sécurité ou démarche externe.
6. Suivi : statut, relance, rendez-vous, contrôle exécution.
7. Clôture : prestation faite, preuve, information locataire, reste à charge éventuel.
8. Capitalisation : récurrence, bâtiment, prestataire, pathologie, nuisance répétée.

## Règles d'orientation
- Partie commune simple : gardien ou responsable de cité.
- Partie commune technique : responsable de cité + technicien.
- Logement privatif simple : qualifier entretien courant / bailleur / photo utile.
- Logement privatif technique : technicien.
- Nuisance : gardien/responsable de cité, puis recours si répétée.
- Sinistre : sécurité + assurance + bailleur + technicien selon origine.
- Danger immédiat : secours ou consigne sécurité avant circuit normal.

## Délais indicatifs
Les délais dépendent du bailleur et des marchés ; ne pas promettre de délai fixe sans information interne.
Prioriser plutôt par criticité :
- Sécurité : immédiat / urgent.
- Sinistre actif : très prioritaire.
- Équipement collectif bloquant : prioritaire.
- Partie commune non dangereuse : traitement de proximité.
- Menu travail : planifiable.
- Nuisance répétée : suivi par preuves et relances.

## Clôture
- Clôturer seulement si l'action est réalisée ou si le dossier est transmis au bon niveau avec information claire au locataire.
- Joindre preuve : photo, retour gardien, retour prestataire, compte rendu technicien.
- En cas d'échec ou de récidive : rouvrir ou escalader.

## Recours
- Si la demande reste sans réponse : relance écrite puis recours selon fiche juridique.
- Si le problème relève d'un tiers : preuves + conciliation/mairie/police/tribunal selon gravité.
- Si désaccord de charge : décret réparations locatives, vétusté, état des lieux, conciliation.
- Si assurance : déclaration sinistre et suivi assureur.

## Exploitation dashboards
- Locataire : statut lisible, prochaine action, demande photo, consigne sécurité.
- Gardien : file de constats et petites interventions.
- Responsable de cité : file parties communes, nuisances, marchés, prestataires, contrôles.
- Technicien : tickets techniques, pièces, photos, accès, urgence, diagnostic.
- Admin/bailleur : pilotage global, coûts, délais, récurrences, responsabilités, recours.
