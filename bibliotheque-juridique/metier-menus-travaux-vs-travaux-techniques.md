# Fiche opérationnelle — Menus travaux vs travaux techniques
Source professionnelle : ANIL, Service-Public, pratiques de gestion de proximité
Date de publication : fiche interne — 2026-06-26
Version : opérationnelle

## Résumé
Les menus travaux sont les petites interventions simples, non dangereuses, souvent liées à l'entretien courant, à la propreté, à la petite maintenance ou à une prestation de proximité.
Les travaux techniques sont les interventions qui demandent un diagnostic, une habilitation, un corps d'état spécialisé, un contrôle de sécurité, une entreprise ou un budget technique.
La frontière n'est pas seulement la taille du problème : une petite fuite visible peut être simple si elle vient d'un joint accessible, mais technique si elle vient d'une canalisation encastrée ou collective.
Le responsable de cité pilote souvent les menus travaux de parties communes et les prestataires courants.
Le gardien peut constater, traiter certains petits sujets autorisés ou suivre l'entreprise.
Le technicien prend le relais lorsque la cause est technique, dangereuse, répétitive, structurelle ou incertaine.
Pour Grock, la règle est : simple / accessible / sans danger / courant = menu travail possible ; réseau / sécurité / encastré / collectif / bâti / récidive = technique.

## Points clés
- Menu travail : petit, visible, accessible, non dangereux, souvent proximité.
- Travail technique : diagnostic, sécurité, réseau, structure, entreprise spécialisée.
- Qui paie dépend de la cause : entretien courant, vétusté, défaut, collectif ou usage anormal.
- Un même objet peut changer de catégorie selon sa cause.
- La photo et le constat terrain aident à trancher.

## Exemples menus travaux
- Ampoule de partie commune.
- Petit réglage de fermeture non dangereux.
- Poignée desserrée, graissage simple, petit affichage.
- Encombrant à signaler / faire enlever.
- Nettoyage renforcé après salissure en parties communes.
- Petit défaut de propreté, paillasson, local poubelle.

## Exemples travaux techniques
- Fuite encastrée, colonne, réseau collectif.
- Tableau électrique, odeur de brûlé, prise noircie.
- Gaz, VMC collective, ventilation dangereuse.
- Infiltration toiture/façade.
- Ascenseur, portail motorisé, interphone collectif complexe.
- Menuiserie bloquée avec défaut matériel ou sécurité d'accès.

## Cas limites
- Joint accessible : réparation locative possible, sauf vétusté ou défaut.
- Serrure : clé perdue = locataire probable ; mécanisme bloqué/usure = technique bailleur possible.
- Ampoule : logement = locataire ; cage d'escalier = partie commune.
- Siphon : accessible = locatif possible ; douche sans trappe / encastré = technique bailleur.
- Nuisance sonore : pas technique sauf équipement défectueux, vibration, VMC, ascenseur ou local technique.

## Recours
- Si la qualification est contestée : demander la cause retenue, le constat et le texte de référence.
- Si facturation locataire : vérifier décret réparations locatives, vétusté et état des lieux.
- Si prestation non réalisée : relance responsable de cité / bailleur, puis recours officiels.
- Si danger : traiter comme urgence technique avant débat de charge.

## Exploitation dashboards
- Locataire : affichage "petite intervention", "travail technique", "à votre charge probable", "à vérifier".
- Gardien : actions simples autorisées et demandes à escalader.
- Responsable de cité : menus travaux, marchés, prestataires, relances.
- Technicien : tickets techniques qualifiés avec cause probable.
- Admin : statistiques menu/technique, coûts, délais, prestataires.
